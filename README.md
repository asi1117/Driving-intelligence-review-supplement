# Supplementary Data

This repository contains the literature dataset and study-selection records for:

**Beyond Racing Games: A Survey of Driving Intelligence Across Virtual Environments**

## Files

### `01_Final_included_reports.xlsx`

Contains the 452 included publication reports, with bibliographic information, article links, classifications, experimental details, and evidence appraisal. The `Field guide` worksheet explains the fields and coding conventions.

### `02_Selection_flow.xlsx`

Documents the selection process through separate worksheets:

- Records identified from databases: 3,255
- Duplicate records removed: 976
- Records screened: 2,279
- Records/reports removed during selection: 1,830
- Reports included from databases: 449
- Additional reports from citation searching: 3
- Final included reports: 452

The removal worksheet includes a reason for each record.
